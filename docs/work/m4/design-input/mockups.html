Cards on a canvas

This is the accepted design for PIO's terminal screen. Panes are cards on a grid canvas, so there are no divider lines to get wrong. Attention lives on two sticky notes. Orchestrate is a team diagram with a message thread. The builder implements against these screens and records every deviation with its reason.

Why this is clearer

  • The diagram answers "who is on the team and who leads"
  • The thread answers "who told whom what, and did it arrive"
  • Each card shows only its latest step. The full session is one key away.

Rules that stay

  • Every message has delivery proof. An unproven one shows violet, never two ticks.
  • A run can never answer another run's permission request
  • The lead has a budget, and everything it starts counts against it
Choosing Medium

What "a harness can lead" adds to the plan

You chose Medium for v0.1. That is a real scope change, so here is its honest cost before the builder hears about it.

  • A Protocol proposal. A message must record which run wrote it. Today only a person can author one. This goes to the Protocol repository first, not into PIO quietly.
  • A small tool for the lead. The leading harness needs a way to start runs and send messages through PIO. For Claude Code that means passing it a tool for that one session, which bends "exactly as you configured it". It needs your explicit approval, the way the test-only model exception did.
  • Steering for Claude Code. Codex can take a message mid-turn. The Claude host cannot yet, so a message to a Claude run waits for its next turn and the thread must say "queued".
  • A new milestone. I suggest M4b, after the board and split view work, so the core screens are not held up.

I will write this up for the builder only after you are happy with the screen.

Can a terminal really look like this

Two tiers of the canvas skin

TierWhereWhat you get
DrawnGhostty, Kitty, WezTermA real image sits underneath the text: grid lines, hand-drawn card outlines and arrows. These terminals support pictures behind text, and that is the out-of-the-box part of this idea.
CharacterEvery other terminalThe same layout with a dotted grid, round corners and arrows made of characters. Clean and readable, less hand-drawn.

The Drawn tier is new ground. I would ask the builder for a one-day experiment in Ghostty before committing to it. If it fails, the Character tier still delivers the cards, the grid and the colors. Your font stays your choice in Ghostty. This page uses Recursive Mono Casual.
